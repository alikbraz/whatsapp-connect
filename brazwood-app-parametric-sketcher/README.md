# סביבת שרטוט פרמטרית לאפליקציית הגגות (brazwood-app)

הקוד כאן שייך לריפו **`alikbraz/brazwood-app`** (אפליקציית הגגות — Vite + React + TS),
לא ל־whatsapp-connect. הסשן נפתח על whatsapp-connect, ולכן העבודה נמסרת כאן כסדרת
פאצ'ים מוכנה ל־`git am`, יחד עם עותק קריא של הקבצים החדשים וצילומי מסך מהאימות בדפדפן.

## התקנה ב-brazwood-app

```bash
cd brazwood-app
git checkout -b feat/parametric-sketcher main        # הפאצ'ים נבנו מעל e9f2b72 (main)
git am /path/to/brazwood-app-parametric-sketcher/patches/*.patch
npm install
npm test          # 4,027 בדיקות עוברות (23 חדשות); כישלון אחד קיים מראש: cutting/auth דורש משתני Supabase
npx tsc -b        # 0 שגיאות
npm run lint      # נקי
npm run dev       # גג → שלב 02 "מתאר ומידות" → "שרטוט פרמטרי — קירות, עמודים, קורות"
```

`roofwizard-integration.diff` הוא רק החלק של האינטגרציה (types / persist / state / history /
RoofWizard), לעיון מהיר.

## מה נבנה (לפי סעיפי הבריף)

### 1. מידות ויחסים גאומטריים — `src/parametric/solver.ts`, `model.ts`
פותר אילוצים נומרי (Levenberg–Marquardt, ריבועים פחותים על קואורדינטות כל הנקודות),
עם מונחי "הישארות" חלשים כך שהשרטוט זז **מינימלית** — רק מה שהיחסים מחייבים.
אילוצים: אופקי, אנכי, מקביל, ניצב, על אותו ציר (collinear), אורכים שווים, זוויות שוות,
נקודות מחוברות, נקודה על קו, נקודת אמצע, סימטריה סביב ציר, מרכוז בין שני קווים,
קיבוע נקודה, מרווחים שווים; ומידות מניעות: אורך, מרחק נקודה–נקודה, מרחק נקודה–קו
(חתום, כולל היסט לפני קיר), מרחק קו–קו, זווית. משיק לקשת — שמור לשלב הקשתות.

### 2. אובייקטים בעלי משמעות — `model.ts`, `objects.ts`
קיר חוץ/פנים (עובי, גובה, איזה קו שורטט: מרכז/פן A/פן B), עמוד (חתך, כיוון, גובה),
קורה (חתך, חומר, מפלס, נקודות תמיכה), פתח בקיר (רוחב, גובה, סף, מיקום), מתאר גג,
קצה גג / גבול מפתח, קו עזר / ציר / רשת. לכל אובייקט שם/קוד; **התפקיד המבני
(נושא / לא נושא / ללא) הוא שדה נפרד מהסוג** ומתועד ככוונת משתמש בלבד.

### 3. יחסים בין רכיבי המבנה — `relations.ts`
יחסים מבניים נשמרים כרשומה אחת (ניתנת לבחירה, עריכה ומחיקה) ומקומפלים לאילוצים בכל
פתרון מחדש (שינוי עובי קיר מעדכן אוטומטית את היסטי הפנים):
עמוד על ציר · עמוד בפינת קיר (מרחק מכל פן/מרכז) · מרחק מקיר (מפני הקיר, לא רק מקו
המרכז) · קורה בין שתי תמיכות (עמוד/קיר/קורה, נרשם ב-`supports`) · יישור לפי מרכז/פן
של קיר או קורה · חלוקה מקומית של עמודים בין שני גבולות (לפי מספר או מרווח) · בליטת גג
ביחס לפן החיצוני של קיר חוץ. מפלסים/שיפוע — מאפיינים (`levelM`, `roofSlopePct`).
קיבוע/נעילה של אובייקט או שכבה מגדיר מה נשאר קבוע; השאר זז יחד לפי היחסים.

### 4. התנהגות פרמטרית ברורה — `analysis.ts`, `doc.ts`
- מידה **מניעה** (אילוץ) לעומת מידה **ייחוס** (מדידה בלבד, בסוגריים) — ניתן להחליף.
- דרגות חופש מחושבות מדרגת היעקוביאן; נקודות חופשיות (חלולות, כחולות) לעומת מוגדרות
  (מלאות) מוצגות על הבד ובצ'יפ העליון.
- סתירה: האילוצים הסותרים והאובייקטים המעורבים מודגשים באדום; הגאומטריה נשארת במצב
  העקבי האחרון; **שום אילוץ לא נמחק ולא משתנה בשקט** — המשתמש מוחק/עורך.
  יחס כפול-אך-עקבי מסומן "כפול" ולא כסתירה.
- כל יחס/מידה ניתנים לבחירה (לחיצה על התג), עריכה (ערך בפאנל או בלחיצה על המידה) ומחיקה.
- שינוי שמזיז רכיבים נוספים מציג תצוגה מקדימה (רוח רפאים מקווקו + רשימת המושפעים)
  עם "אשר/בטל".
- המסמך נשמר בתוך `RoofModel.parametricSketch` → snapshot הגג → localStorage;
  נבדק: סגירה, רענון דף, פתיחה מחדש.

### 5. סביבת העבודה — `ui/`
חלון מלא קבוע (ללא גלילת עמוד), גלגלת = Zoom סביב הסמן, כפתור אמצעי / כלי יד = Pan,
Zoom to Fit (F), רשת (G), הצמדה (נקודות, חיתוכים, אמצעים, על קו, אופקי/אנכי, רשת),
Undo/Redo (Ctrl+Z / Ctrl+Y, גם גרירה = צעד אחד), הקלדת אורך תוך כדי שרטוט + Enter,
פאנל מאפיינים קומפקטי, שכבות עם הצגה/נעילה.

### 6. חיבור למודל הגג — `roofBridge.ts`, `state.ts` (`adoptParametricSketch`)
המתאר נגזר ממתאר-גג משורטט או מפני החוץ של קירות החוץ (חיתוך פינות); הפאנל מציג
"הגג נשען על: …" והרשימה נשמרת ב-`roofSupports`. "צור/עדכן גג מהשרטוט" עובר באותו
מסלול של ייבוא DXF (קירות חופשיים), שומר eave/gable כשמספר הקירות לא השתנה, ומיישם
בליטות גג לכל צלע מיחסי `roofOverhang`.

### 7. סדר הביצוע והבדיקה
`scenario.test.ts` מריץ את התרחיש המלא: קירות חוץ → קיר פנים → עמודים → קורה נושאת →
מידות ויחסים → גזירת גג; ואז שינוי מידה (10→14 מ') ושינוי זווית (90°→80°) — כל היחסים
נשמרים, הקורה נשארת על העמודים, העמוד נשאר ממורכז, הגג עוקב; סתירה; Undo/Redo;
שמירה ופתיחה מחדש; נעילה; חלוקה; מחיקה בטוחה. `parametricAdopt.test.ts` בודק את
האימוץ למודל הגג. `screenshots/` — אימות בדפדפן (Playwright) של אותו תרחיש דרך ה-UI,
כולל תצוגה מקדימה, סתירה, גג שנבנה (12.25×6.25 מפני החוץ) ופתיחה מחדש אחרי רענון.
